# Blueprint Generator 使用指南

## 概述

Blueprint Generator 是一个独立的管理窗口，用于自动生成和管理 `BlueprintBehavior` 对应的 `ShizukuBluePrint` 子类。

## 打开窗口

通过 Unity 菜单打开：
```
Shizuku > Blueprint Generator
```

## 窗口功能

### 1. 自动扫描

窗口会自动扫描项目中所有继承自 `BlueprintBehavior<T>` 的类，包括：
- 显示类名
- 显示生成状态（已生成 / 未生成）
- 显示已生成脚本的路径

### 2. 生成蓝图类

对于**未生成**的类：
- 点击 **"Generate"** 按钮自动生成对应的 Blueprint 类
- 生成的类会放在与 Behavior 类相同的目录下
- 生成的类会自动添加 `[CreateAssetMenu]` 特性

### 3. 重新生成

对于**已生成**的类：
- 点击 **"Regenerate"** 按钮重新生成代码
- 会覆盖原有文件（请注意备份自定义代码）

### 4. 定位脚本

对于**已生成**的类：
- 点击 **"Locate"** 按钮在 Project 窗口中定位脚本文件

### 5. 刷新列表

点击右上角的 **"🔄 Refresh"** 按钮重新扫描所有类。

## 使用流程

### 步骤 1：创建 Behavior 类

```csharp
using UnityEngine;

public class MyEnemyBehavior : BlueprintBehavior<MyEnemyBehavior>
{
    [SerializeField] protected float health = 100f;
    
    [BlueprintOverridable]
    protected virtual void OnDeath()
    {
        if (TryExecuteBlueprintOverride(nameof(OnDeath)))
            return;
        
        Debug.Log("Enemy died!");
    }
}
```

### 步骤 2：打开 Blueprint Generator

```
Shizuku > Blueprint Generator
```

### 步骤 3：生成 Blueprint 类

1. 在列表中找到 `MyEnemyBehavior`
2. 点击 **"Generate"** 按钮
3. 等待生成完成

### 步骤 4：验证生成

生成的代码类似：

```csharp
using UnityEngine;

/// <summary>
/// Blueprint class for MyEnemyBehavior
/// Auto-generated by Blueprint Generator
/// </summary>
[CreateAssetMenu(fileName = "MyEnemyBehaviorBlueprint", menuName = "Shizuku/Blueprint/MyEnemyBehavior Blueprint")]
public class MyEnemyBehaviorBlueprint : ShizukuBluePrint<MyEnemyBehavior>
{
    // You can override InitializeBehavior to add custom initialization logic
    // public override void InitializeBehavior(MyEnemyBehavior behavior)
    // {
    //     base.InitializeBehavior(behavior);
    //     // Custom initialization here
    // }
}
```

### 步骤 5：创建 Blueprint Asset

1. 右键 Project 窗口
2. 选择 `Create > Shizuku > Blueprint > MyEnemyBehavior Blueprint`
3. 创建一个 Blueprint 资源文件

### 步骤 6：使用 Blueprint

1. 在场景中创建一个 GameObject
2. 添加 `MyEnemyBehavior` 组件
3. 将创建的 Blueprint Asset 拖到 Blueprint 字段
4. 双击 Blueprint Asset 打开可视化编辑器

## 注意事项

### ⚠️ 重新生成会覆盖文件

如果你在生成的 Blueprint 类中添加了自定义代码，重新生成会**覆盖所有内容**。建议：
- 自定义逻辑放在 Behavior 类中
- 或者手动编辑生成的 Blueprint 类后不再使用重新生成功能

### ✅ 生成路径规则

1. **首选路径**：与 Behavior 类相同的目录
2. **备选路径**：`Assets/Scripts/Graph/Blueprint/`

### 🔄 何时需要刷新

以下情况需要点击 "Refresh" 按钮：
- 新增了 BlueprintBehavior 子类
- 手动删除了生成的 Blueprint 类
- 重命名了 Behavior 类

## 状态说明

### ✓ Generated (绿色)
- 表示已经生成了对应的 Blueprint 类
- 可以使用 "Regenerate" 和 "Locate" 功能

### ○ Not Generated (橙色)
- 表示尚未生成 Blueprint 类
- 可以点击 "Generate" 按钮生成

## 故障排除

### 问题：找不到我的 Behavior 类

**解决方案**：
1. 确保类继承自 `BlueprintBehavior<T>` 且 T 是自身
2. 确保类不是 abstract 或 interface
3. 点击 "Refresh" 按钮重新扫描

### 问题：生成后找不到 CreateAssetMenu

**解决方案**：
1. 等待 Unity 编译完成
2. 刷新 Project 窗口（Ctrl+R）
3. 重启 Unity 编辑器

### 问题：路径显示为空

**解决方案**：
1. 这是正常的，表示脚本名称与类名不匹配
2. 手动搜索 Project 窗口中的脚本文件

## 高级用法

### 自定义初始化逻辑

生成的 Blueprint 类中有注释提示，可以取消注释并添加自定义逻辑：

```csharp
public override void InitializeBehavior(MyEnemyBehavior behavior)
{
    base.InitializeBehavior(behavior);
    
    // 自定义初始化逻辑
    Debug.Log("Custom initialization for MyEnemyBehavior");
}
```

### 批量生成

如果有多个未生成的类，可以逐个点击 "Generate" 按钮快速生成。
